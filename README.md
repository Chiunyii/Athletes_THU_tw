# 東海體能社團站

東海大學體能性社團幹部專用的行政資訊站：行政公告、截止日提醒、主題資訊查詢、新任幹部上任清單，以及課外組位置與辦公時間。

## 網站有什麼

首頁 `index.html` 是一座用 Three.js 做的 3D「行政島」：一座明亮的大島，中央是課外組與圓環，連絡道路通到外圈環狀道路，各行政分類的建築沿外圈排列，角色會沿著道路走到各建築區。介面採奶油色卡片、右側直排選單與底部資訊抽屜。`list.html` 是內容相同的文字版，給舊手機或想快速查找的人。

> 版權說明：畫面只參考一般手遊常見的版面配置與配色手法。所有角色、建築、圖示都是本站以程式繪製的原創內容，沒有使用任何既有遊戲的角色、標誌、圖片或字型；字型使用 Google Fonts 上的開源字型（Noto Sans TC、Baloo 2），圖示使用系統表情符號。

**建立角色（選填）**：第一次進站會看到 4 步引導，最後一步可以選「開始探索」直接逛，或「建立角色」。之後隨時可以從右上「角色」設定。
- 名字、身份（課外組，或 26 個體能性社團之一）、職位（社長、副社長、財務、活動長、器材長、公關、幹部、社員、輔導老師）、球衣／髮色／膚色。
- 每個社團有自己的道具：籃球、排球、球棒、羽球拍、弓、竹劍、拳擊手套、黑帶、飛盤、滑板、瑜珈墊、登山背包、啞鈴、泳圈、號碼布、彩球、急救包、馬術帽等；課外組拿的是資料夾板和識別證。
- 角色分頁：「外觀」、「行程」（幹部護照、「帶我逛一圈」自動導覽、上任清單）、「拍照」（和角色合照，可下載或長按儲存）。

**本島 00：課外組**——以峮老師的巨型角色呈現（齊劉海中長髮，旁邊站著橘白貓與灰白貓），腳邊招牌顯示辦公狀態；圓環經連絡道路接到外圈道路，通往每個行政建築區。

**十一座行政館（01–11）**：本島上有期初會議館（小學教室課桌椅）與經費館（大計算機與硬幣，上方有跳到各段落的按鈕）。另外有三座以木橋相連的小島：「行政島」有社團行政館（只放社團行政任務的打勾清單，右側「任務」按鈕會帶到這裡）、評鑑館、交接館、財產盤點館，四館沿著島上一條主路左右交錯排列；「活動島」有社團活動館（嘉年華）與活動安全館（急救站），中間有登山小山；「場地器材島」有場地借用館（銘賢堂）與器材借用館（大舞台、音響與組裝人員）。`islands` 裡設定相同 `islet` 名稱的館會放在同一座小島（三館以上的小島會變大，館沿著一條主路左右交錯排列），小島方位在 `js/game.js` 的 `ISLET_AT` 調整；全景時小島只顯示島名，放大後才出現各館名牌。角色走到各館時會站在建築的右前方，拍照時不會被擋住。期初會議館最上方有「115-1 期初會議資料」按鈕，並列出期初會議簡報的重點提醒；每學期只要更新 `islands` 裡會議島的 `links`，以及資訊站的 `g-meeting`。每座館的資訊抽屜會列出該分類的攻略、截止日、任務、相關公告。名牌上顯示 D-倒數；7 天內截止，館的上方會浮出黃色菱形，3 天內轉紅。島上也有其他社團的成員走來走去。

右側選單：全景、角色、清單（含搜尋）、截止、任務、公告。

**畫面不會越來越擠**：全景只顯示島名與課外組；啊牛、公告欄、機場、角色名牌和島上的社團成員，要放大後才出現。名牌會依重要程度自動避讓，重疊時較不重要的名牌會淡出（選中的島永遠顯示）。島上的社團成員有固定人數上限，之後新增社團或島嶼也不會變多。拖曳移動群島，兩指（或滾輪）縮放、旋轉。

可以用網址直接開啟某個地點，方便在 LINE 公告時附上：`…/#deadlines`、`…/#news`、`…/#office`、`…/#me`（角色）、`…/#list`，或某座島 `…/#isle-安全（安全館）`。

## 怎麼更新內容（老師／助理）

**只需要修改 `js/data.js`**，3D 島與文字版會同時更新。 在 GitHub 網頁上打開這個檔案，按鉛筆圖示編輯，存檔（Commit）後約 1 分鐘網站就會更新。

- 新增截止日：在 `deadlines` 裡複製一段 `{ ... }`，改 `id`（不可重複）、`title`、`due`（例如 `"2026-11-20 17:00"`）、`category`、`detail`。`category` 填島的分類（行政、活動、經費、場地、安全、器材、評鑑），截止日就會出現在那座島上。已過期的截止日會自動收進「顯示已截止項目」（啊牛的截止日提醒與文字版清單都有），也不會再放進訂閱行事曆，不必手動刪除。
- 公告有截止日：在 `announcements` 那則公告加上 `due`（例如 `"2026-11-20 17:00"`），就會自動出現在啊牛的截止日提醒，分類沿用公告的 `tag`；想讓截止日提醒顯示不同名稱可另加 `dueTitle`；一則公告有好幾個期限時改用 `dues: [{ due, title, link }]`。
- 公告的 `tag`、資訊站主題的 `island` 也用同樣的分類名稱。
- 社團行政任務在 `todos`：`common` 是每學期共同項目，`s1`、`s2` 是第一、第二學期。每一項可以寫 `when`（時間提醒）、`note`（注意事項）、`links`（按鈕）；按鈕網址留空 `""` 會顯示「連結待補」。任務也會出現在對應 `island` 的島上。打勾紀錄依學年度分開，換學年自動重來。
- 想新增或改名一座島：修改 `islands`（名稱、圖示、顏色、建築、介紹），群島會自動重新排列。
- 新增社團：在 `clubs` 加一行 `{ name: "社團名", prop: "道具" }`，道具代號列在 `clubs` 上方的說明。職位清單在 `roles`。
- 新增公告：在 `announcements` 裡複製一段，`pinned: true` 會置頂。
- 換成正式資料後，把 `isSample` 改為 `false`，「範例資料」提示條就會消失。
- 國定假日與補假：`office.holidays` 已內建 2026–2027 年政府行政機關辦公日曆（資料來源：行政院人事行政總處，經 github.com/ruyut/TaiwanCalendar 整理）；正式網站開啟時也會自動下載當年與下一年的最新日曆，所以之後年度不必手動更新。學校另外公告的停止辦公日（校慶補假、颱風停班）填在 `office.closedDates`，補班日填在 `office.workdays`。
- 課外組導航完成後，把 Google 地圖網址貼到 `office.mapUrl`，頁面會自動出現「開啟 Google 地圖導航」按鈕。

## 推播與提醒怎麼做到

靜態網站本身無法主動推播，所以本站用三層方式讓提醒找到學生：

1. **訂閱社團行事曆（最推薦）**：網站部署時會自動由 `js/data.js` 產生 `calendar.ics`。學生按「訂閱社團行事曆」後，之後新增的截止日會自動同步到手機行事曆，並在截止前 3 天、1 天提醒（iPhone 行事曆支援提醒；Google 日曆訂閱的提醒需學生自行設定預設通知）。
2. **單項加入行事曆**：每個截止日都有「Google 日曆」與「iPhone／其他行事曆」按鈕。
3. **網頁通知**：學生允許後，每天第一次開啟網站時會通知 3 天內的截止日。

建議搭配：LINE 社群仍作為「通知入口」，公告時只貼一句重點加上本站連結（例如 `…/#deadlines`），讓學生養成「點進來看」的習慣。

## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages**，Source 選 **GitHub Actions**。
2. 推送到 `main`（或 `master`）分支，`.github/workflows/pages.yml` 會自動產生 `calendar.ics` 並發佈網站。

本機預覽：因為 3D 版使用 JavaScript 模組，請用本機伺服器開啟，例如在資料夾中執行 `python3 -m http.server` 後瀏覽 http://localhost:8000 。文字版 `list.html` 可直接雙擊開啟。手動產生行事曆檔：`node scripts/build-ics.js`。

## 檔案結構

```
index.html             3D 群島首頁（介面與樣式）
js/game.js             3D 群島程式（Three.js）
list.html              文字版
js/data.js             所有內容：公告、截止日、主題資訊、課外組資訊
scripts/build-ics.js   由 data.js 產生 calendar.ics
calendar.ics           可訂閱的行事曆檔（部署時自動重新產生）
.github/workflows/     GitHub Pages 自動部署
```


**打勾與閱讀紀錄**：任務打勾、公告已讀、集章與角色設定都存在學生自己瀏覽器的 localStorage（以 `thuarch:` 開頭），重新打開連結會接著顯示；換手機、換瀏覽器或清除網站資料才會重新開始。

**路牌**：機場路口有一支東海大學風格的指路牌（深咖啡色木牌、白色箭頭、下方英文），指向課外組、各館與兩座小島；小島入口的島名牌也是同樣風格。各館英文名寫在 `islands` 的 `en`。

**課外組峮老師**：本島的巨型角色；資訊卡上有「常用表單」（校外競賽填報、校內指導老師聘任申請表、校外指導老師法規與相關表單），內容寫在 `office.forms`。

**島上的熱鬧造景**：本島上有籃球、羽球、排球、足球、跆拳道、空手道、八方傳統武術（分散在草地上）、射箭、馬術圍欄與草地上騎馬散步、沿外圈道路騎單車的角色，海邊有游泳（露出戴泳帽、泳鏡的頭划水，其中一位套著游泳圈）與自由潛水（面鏡、呼吸管，下潛時穿黃色蛙鞋的腳翹出水面、水下冒泡泡，旁邊有紅白潛水旗浮球）的角色，造型參考社團島（純造景，不能點）。小秘書啊牛站在外圈道路外、機場路的右側。

**校外競賽群島**：從行政島主路盡頭再以木橋往外延伸的小島（`js/game.js` 的 `ISLET_FROM`），上面是校外競賽館（頒獎台、獎盃與各校旗幟），有填寫說明、電子表單上傳與文件下載。

**收合**：各館與截止日清單裡的截止日、公告預設都是收起的，點標題才展開。

**颱風假自動標示**：`.github/workflows/typhoon.yml` 每 30 分鐘執行 `scripts/typhoon.js`，讀取行政院人事行政總處「天然災害停止上班及上課情形」中臺中市的公告，寫入 `typhoon.json`。網站開啟時（之後每 10 分鐘）讀取這個檔：臺中市宣布停止上班的日子，課外組狀態顯示「颱風假」、本週辦公時間標示「不辦公（颱風假）」；只停下午或上午時，只保留有上班的時段並註明。也可以在 `office.closedDates` 手動加上 `{ "2026-11-03": "颱風假" }`。GitHub 的排程若 60 天沒有任何提交會自動暫停，需要到 Actions 頁面重新啟用。
